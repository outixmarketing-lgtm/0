# Airix Workspace — v1.1

واجهة عربية للتسعير والمنتجات والمخزون والباندلز والطلبات والمصروفات.

## تشغيل سريع

افتح `index.html` في متصفح حديث. الملف مستقل ويحتوي التنسيق والكود، ولا يحتاج تثبيت مكتبات أو إنترنت للتشغيل المحلي.
إذا منع متصفحك التخزين للملفات المحلية، استخدم نسخة مستضافة أو سيرفر محلي.

## أول استخدام

1. من المنتجات، راجع التكاليف والأسماء والمقاسات. البيانات الأولية مأخوذة من صورة التسعير وليست قائمة أسعار نهائية.
2. استكمل البنود ثم أكد أنك راجعت التكلفة. لا يمكن إنشاء طلب لمنتج لم تراجع تكلفته.
3. من حاسبة التسعير، اختر الزيادة على التكلفة أو هامش الربح أو سعرًا مباشرًا؛ ثم اعتمد التكلفة والسعر النهائي.
4. من المخزون، سجّل الرصيد الافتتاحي الفعلي. جميع الكميات تبدأ بصفر.
5. أنشئ باندلز حسب احتياجك؛ عند تسليم طلب الباندل تُخصم مكوناته الأصلية.
6. سجّل طلبًا وعربونًا. حالة التجهيز لا تخصم أو تحجز مخزونًا. تأكيد التسليم يتحقق من الكميات ويخصمها مرة واحدة.
7. سجّل دفعات التحصيل حتى قيمة الطلب. إلغاء طلب مُسلّم يعيد كل كمياته: استخدمه فقط لمرتجع كامل استلمته بالفعل.
8. صدّر نسخة JSON بانتظام. CSV مخصص لتصدير قائمة المنتجات وليس نسخة استعادة كاملة.
9. من الإعدادات يمكنك رفع شعار PNG/JPG/WebP؛ لذلك لا تحتاج تعديل الكود لتغيير الشعار.

## حدود واضحة

- البيانات محفوظة في localStorage على المتصفح والجهاز الحالي فقط. ليست قاعدة بيانات سحابية.
- لا توجد حسابات أو تسجيل دخول أو مزامنة بين الأجهزة. لا تضع التطبيق على جهاز مشترك للبيانات الحساسة.
- رفع الموقع على Vercel لا يرفع بيانات المتصفح. الرابط نفسه على جهاز آخر يبدأ ببيانات أولية مستقلة.
- تغيير النطاق، حذف بيانات المتصفح أو استخدام التصفح الخاص قد يؤدي لغياب البيانات. استعد JSON عند الانتقال.
- حد التخزين تابع للمتصفح؛ هذه النسخة مناسبة كبداية صغيرة وليست نظامًا متعدد المستخدمين.
- الطلب يحفظ أسعار وتكاليف وقت الإنشاء، فلا تعيد أسعار المنتجات الجديدة كتابة أرباح الطلبات القديمة.
- لا توجد مرتجعات جزئية أو سجل تفصيلي لكل دفعة أو تكامل دفع أو فواتير ضريبية أو ضريبة تلقائية.
- الإلغاء لا يرد المال آليًا؛ المدفوع يبقى كسجل تاريخي، وتُستبعد الطلبات الملغاة من المستحقات والربح.
- الربح المعروض تقديري: مبيعات الطلبات المسلّمة ناقص تكاليفها المسجلة وناقص المصروفات الإضافية منذ البداية. لا يساوي رصيد نقدي أو صافي ربح محاسبي معتمد.
- لا تكرر تكلفة التسويق أو الشحن في تكلفة المنتج ثم المصروفات؛ لتجنب خصمها مرتين.
- شحن التوريد في الحاسبة هو حصة الوحدة، وليس شحن دفعة كاملة. الشحن الذي تدخله ضمن التكلفة هو ما تتحمله أنت.
- الستاند محدد 10 × 15 حسب قائمة المنتجات، رغم اختلاف الصورة 10 × 20؛ راجع تكلفة المقاس الفعلي.
- التاج يحتاج تأكيد نوعه ووظيفته، ولم نفترض أنه جهاز تتبع.

## الرفع على Vercel

انشر هذا المشروع كملفات ثابتة. لا يحتاج Build Command أو حزم أو مفاتيح سرية.

1. فك الضغط وارفع الملفات إلى مستودع Git جديد.
2. في Vercel اختر New Project ثم استورد المستودع.
3. اختر Framework Preset: Other.
4. اترك Build Command فارغًا، واجعل Output Directory هو `.` (جذر المشروع)، ولا تحتاج Install Command.
5. ملف `vercel.json` يحدد إعدادات الملفات الثابتة وبعض ترويسات الحماية.
6. انشر وافتح الرابط، ثم استعد ملف JSON إذا كنت نقلت بياناتك من نسخة محلية.

راجع شروط خطة الاستضافة حسب استخدامك. هذه الحزمة جاهزة للرفع لكنها لم تُنشر على حسابك تلقائيًا.

## ملفات المطوّر

- index.html: النسخة النهائية المستقلة الجاهزة للتشغيل.
- app.js: الواجهة وإدارة البيانات.
- core.js: حسابات التسعير وحركات تسليم/إلغاء الطلبات.
- style.css: التصميم المتجاوب.
- build.py: إعادة تجميع index.html بعد تعديل الملفات المصدر.
- test.cjs: اختبارات منطق الأعمال والحفظ والتحقق؛ شغّل `node test.cjs`.
- vercel.json: إعداد الاستضافة الثابتة.

التحقق المنفذ: صحة JavaScript، الزيادة والهامش والخصم، تحذير الخسارة، خصم مكونات باندل متداخلة، منع التسليم المكرر، إعادة مخزون المرتجع، رفض نقص المخزون دون تعديل جزئي، التحقق من الاستيراد، تراجع عملية الحفظ غير الصالحة، ودورة حفظ/قراءة البيانات.
لم تتوفر معاينة متصفح مرئية في بيئة التنفيذ؛ لذلك يلزم فحص بصري على جهازك بعد الفتح.

## تحديث 1.1 — اللوجو وإدارة المنتجات
- شعارك الأصلي SVG مدمج داخل التطبيق، بنفس اللون والمسارات، ولا تحتاج رفعه مجددًا.
- إضافة وتعديل ونسخ المنتجات متاحة من صفحة المنتجات، بدون حساب أو دور إداري منفصل في هذه النسخة المحلية.
- المنتج غير المستخدم وذو الرصيد الصفري يُحذف نهائيًا بعد التأكيد.
- المنتج الذي له رصيد أو طلبات أو حركات أو باندلز يُؤرشف لحماية السجلات. فعّل «عرض المؤرشف» ثم «استعادة» لإرجاعه.
- المنتج المؤرشف والباندل الذي يحتويه لا يظهران عند إنشاء طلب جديد. تظل حركاته وطلباته السابقة محفوظة.
- نسخ المنتج يولّد كودًا جديدًا وبرصيد صفر.
- لتحديث نسخة قديمة: صدّر JSON أولًا ثم استبدل ملفات التطبيق. نفس نطاق الاستضافة يحتفظ بالبيانات الحالية. لا توجد صلاحيات مستخدمين فعلية لأن التطبيق بلا تسجيل دخول.
